# AirFare ✈️

AirFare is a Machine Learning-powered web application built with Streamlit that predicts and compares flight ticket prices based on user inputs such as airline, source, destination, journey date, and travel duration. The project helps users estimate airfare prices and make better travel decisions.

📌 Features
- Flight ticket price prediction using Machine Learning
- Interactive Streamlit web application
- Compare airfare prices across flights
- User-friendly and responsive interface
- Real-time input-based predictions
- Fast and efficient prediction system


🛠️ Tech Stack
- Python
- Streamlit
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Pickle

  ▶️ Run the Streamlit Application

Use the following command to start the application:


streamlit run app.py


The application will automatically open in your browser.


🎯 How It Works
Select:
- Airline
- Source city
- Destination city
- Journey date
- Departure time
- Arrival time
- Total stops
- Click on the Predict Price button
The model predicts the estimated flight fare instantly.
